# 📊 Amazon Sales Analysis Dashboard (Power BI)

## 📌 Project Overview
This project presents an **Amazon Sales Analysis Dashboard** built in **Power BI**.  
The dashboard provides a comprehensive view of sales performance, customer engagement, and product trends.  

The goal of this analysis is to help stakeholders make **data-driven decisions** by tracking KPIs such as revenue, product sales, and customer reviews.

---

## 🛠 Tools & Technologies
- **Power BI Desktop** – for data modeling and dashboard design  
- **Excel/CSV** – dataset source  
- **DAX (Data Analysis Expressions)** – for calculated measures and KPIs  

---

## 📂 Dataset
The dataset includes sales and product details such as:  
- Product Category  
- YTD (Year-to-Date) & QTD (Quarter-to-Date) Sales  
- Number of Products Sold  
- Customer Reviews  
- Time Dimensions (Month, Week, Quarter)  

*(Dataset file is available in the `/data` folder.)*

---

## 🚀 Key Dashboard Features
- 📌 **KPIs** – YTD Sales, QTD Sales, Products Sold, Reviews  
- 📈 **Sales by Month & Week** – trend analysis for different time periods  
- 🛍 **Sales by Product Category** – contribution of each category  
- ⭐ **Top 5 Products by Sales & Reviews** – best performers at a glance  
- 🎛 **Interactive Filters** – filter by Product Category & Quarter
